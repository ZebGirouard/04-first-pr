# 04 First PR

## Goal
Practice the real GitHub workflow: fork, clone, make one small fix, push, and open a pull request that explains the task you completed.

## Start Here
1. Fork this repo on GitHub.
2. Clone your fork.
3. Pick one open task from `issues.md`.
4. Make exactly one small change in `contributors.md` or `ideas.md`.
5. Commit it, push it, and open a pull request back to the original repo.

If you do not have Git installed yet, that is the only setup step.

## Stretch Goals
- Open a second PR for a different issue.
- Leave one review comment on a classmate's PR.
- Improve the wording in this README.
