# 04 First PR

## Goal
Practice the real GitHub workflow: fork, clone, make one change, push, and open a pull request.

## Start Here
1. Fork this repo on GitHub.
2. Clone your fork.
3. Change one item in `contributors.md`, commit it, push it, and open a pull request back to the original repo.

If you do not have Git installed yet, that is the only setup step.

## Stretch Goals
- Add a second contribution in `ideas.md`.
- Improve the wording in the README.
- Review a classmate's pull request.
